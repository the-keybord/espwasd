# RBFmicro - BBC micro:bit BLE Remote Controller

This folder contains Python code for the **BBC micro:bit** to connect with the **WASD Web Remote** (`index.html`).

---

### How to Flash:
1. Open [MakeCode for micro:bit](https://makecode.microbit.org).
2. Create a new project.
3. Switch the editor from **Blocks** to **Python** (toggle at top).
4. Click **Extensions** (under Advanced or Settings) and select **Bluetooth** (accept removing radio).
5. Open [microbit_remote.py](microbit_remote.py), copy the code, and paste it into the editor.
6. Connect your micro:bit via USB and click **Download** to flash!

---

### Connecting to the Web Remote:
1. Open `index.html` in Chrome or Edge.
2. Click **Connect**.
3. Select your **BBC micro:bit** in the Bluetooth device list.
4. The micro:bit will display a checkmark (`YES`), and you can now drive it with the WASD keys!
